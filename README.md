# 臺灣道路標線圖鑑

依《道路交通標誌標線號誌設置規則》（民國115年03月11日修正）整理的道路標線教學網站，一頁一種標線，附條號、示意圖與常見誤解。

- 網站：https://liu7389.github.io/taiwan-road-markings/
- AI 協作規則：[AGENTS.md](AGENTS.md)

## 使用方式
```
python scripts/build.py       # 由 data/markings.json 產生全部頁面
python scripts/check_site.py  # 檢查是否符合 AGENTS.md 規則
```
只需要 Python 3，不用安裝其他套件。

## 聲明
條文內容為整理摘要，以全國法規資料庫原文為準；示意圖非施工圖。
